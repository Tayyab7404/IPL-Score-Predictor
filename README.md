# IPL Score Predictor

This project is an IPL Score Predictor that forecasts the score of an IPL match using historical data from IPL matches between 2008 and 2017. The project leverages machine learning techniques to make predictions based on various match-related features.

## Introduction

The IPL Score Predictor is designed to predict the scores of IPL matches using historical data. By analyzing past match data, the model aims to provide accurate score predictions, helping fans and analysts to gain insights into potential match outcomes.

## Dataset

The dataset used in this project contains historical data of IPL matches from 2008 to 2017. The data includes various features such as team names, match location, toss details, and match results.

## Features

The following features are considered for prediction:

- Batting team
- Bowling team
- City
- Current score
- Balls left
- Wickets left
- Current run rate
- Target (if available)

## Model

The project utilizes a machine learning model to predict the match score. The model is trained using the historical dataset and employs regression techniques to forecast the score based on the input features.

## Results

The model's performance is evaluated using various metrics, and the results indicate that the model provides reasonably accurate score predictions. Detailed results and evaluation metrics can be found in the notebook.
